# lgwks_macros

The `script!` orchestration language for `lgwks_bot`. Use it as
`lgwks_bot::script!`; this crate is the syntax, and `lgwks_bot::script` is the
runtime every block expands into.

```text
lgwks_bot::script! {
    pub flow crawl(site: &Site, paths: Vec<String>) -> Vec<usize>:
        let pages = each path in paths, at most (site.quota()) at once:
            retry up to 3 times, waiting 200ms:
                within 5s:
                    site.fetch(scope.key(), &path).await.or_retry()?
        give back pages.iter().map(|page| page.len()).collect()
}
```

Every fan-out is bounded, every wait has a deadline, every retry keeps one
idempotency key, every step is keyed by tenant and path, and every script emits
an `ARCHITECTURE` map compiled from the same tokens. See the crate
documentation for the full language and the list of what it refuses.

## The words

Every word of the language, one row each. The macro dispatches on the same
table this is rendered from (`src/lexicon.rs`), and a test refuses a README
whose table differs from it. A line that starts with none of these words is
plain Rust.

| Written | Where | Calls | Means | Refuses | Guarantees |
|---|---|---|---|---|---|
| `[pub] flow name(inputs) [-> Output]:` | flow | `Scope::enter` | an `async fn` taking the tenant `Scope` first and returning `Result<Output, FlowError>` | a promised output the last line never produces | every step keyed by tenant and path (multi-tenant; `tenants_isolated` in `sim_script.rs`); the panicking calls refused by resolved path (idiomatic; refusal *unwrap by path*) |
| `each x in xs:`<br>`each x in xs, at most (limit) at once:` | block | `each` | every item, as many at once as the machine sustains, results in input order, first failure stops the rest<br>the same, under a limit that comes from somewhere named (an upstream's quota) | a concurrency bound typed as a number; a bound outside `1..=65536` | bounded fan-out (hyperscale; `fan_bounded` in `sim_script.rs`); results in input order (generalized; `fan_machine_sized` in `sim_script_fanout.rs`); first failure cancels the rest (hyperscale; `fan_fail_fast` in `sim_script.rs`) |
| `within 2s:` | block | `within` | the block, or `TimedOut` when the deadline passes | a zero duration; a duration with no unit | a deadline, on the scope's clock (hyperscale; `a_within_budget_is_refused_by_an_advance_with_no_real_wait` in `sim_clock_wiring.rs`) |
| `retry up to 3 times[, waiting 100ms]:` | block | `retry` | the block again while it fails transiently, same key each attempt, within the run's retry budget | attempts outside `1..=1000`; a zero wait | one idempotency key across attempts (ephemeral; `retry_one_key` in `sim_script.rs`); attempts within the run's retry budget (hyperscale; `retry_budget_holds` in `sim_script.rs`) |
| `together:` | block | `try_join!` | each line underneath concurrently; `let x = ..` lines bind their result | anything before its `:`; an indent under a line that opens no block | every branch owned by this task (ephemeral; `together_owned` in `sim_script_steps.rs`); first failure cancels the rest (hyperscale; `together_fail_fast` in `sim_script_steps.rs`) |
| `step name:` | block | `Scope::enter` | a named scope: its own key and error location | a name that is not one word | its own step key (ephemeral; `step_own_key` in `sim_script_steps.rs`); failures located at the step (decoupled; `step_failure_located` in `sim_script_steps.rs`) |
| `for x in xs:` | block | `Scope::item` | every item in turn, each in its own scope | a missing pattern or missing items | items in order, one at a time (generalized; `for_in_order` in `sim_script_steps.rs`); one scope per item (ephemeral; `for_scope_per_item` in `sim_script_steps.rs`) |
| `if cond:` / `else if cond:` / `else:` | block | none: Rust `if` | as written | a missing condition | a value only when an `else:` ends the chain (idiomatic; refusal *if with no else as the value*) |
| `else` (see `if`) | block | none: Rust `else` | — | an `else` not after an `if`; an `else:` that is not the last branch | only ever continues an `if` chain (idiomatic; refusal *else without if*) |
| `let x = <block>:` | block | the block's own | the block's last line becomes `x` | a `let` with no `=` or nothing after it | the block's failure propagates before `x` is bound (idiomatic; `let_fails_before_binding` in `sim_script_steps.rs`) |
| `run other(args)` | inline | the callee flow | call another flow in this scope, await it, propagate its failure | — | the callee runs in this tenant's scope (multi-tenant; `run_in_callers_tenant` in `sim_script_steps.rs`) |
| `observe domain::id of target` | inline | `observe` | poll the source the host's registry declares under `domain::id`, built from `target`, as a step of its own; bind it with a type, `let n: u16 = ..` | an identifier with no `of <target>` | an identifier with no `of <target>` is refused at the word, naming the form (idiomatic; refusal *observe with no target*); an identifier the registry lacks refuses the flow before its first step, naming the registry and the nearest identifier (decoupled; `an_unknown_domain_refuses_the_flow_before_any_step` in `sim_script_domains.rs`); the same polls and actions, in the same order, as the `BotSpec` chain over the same registry (generalized; `the_script_trace_is_the_spec_trace` in `sim_script_domains.rs`); the source's capabilities are checked against this run's grant at the step (multi-tenant; `a_domain_short_of_authority_blocks_its_step` in `sim_script_domains.rs`) |
| `act domain::id on target with value` | inline | `act` | run the action the host's registry declares under `domain::id`, built from `target`, on `value`, as a step of its own | an identifier with no `on <target> with <value>` | an identifier with no `on <target> with <value>` is refused at the word, naming the form (idiomatic; refusal *act with no value*); the action runs once, under exactly the grants it declares; an external one settles a repeat by reading its receiver back (ephemeral; `an_external_action_runs_once_under_its_grant` in `sim_script_domains.rs`); the same polls and actions, in the same order, as the `BotSpec` chain over the same registry (generalized; `the_script_trace_is_the_spec_trace` in `sim_script_domains.rs`); an identifier the registry lacks refuses the flow before its first step, naming the registry and the nearest identifier (decoupled; `an_unknown_domain_refuses_the_flow_before_any_step` in `sim_script_domains.rs`) |
| `give back value` | line | none: `return Ok` | return from the flow | `give back` inside a block that has its own value | leaves the flow, never a nested block (idiomatic; refusal *give back from a nested block*) |
| `fail with reason` / `fail transiently with reason` | line | `FlowError::failed` / `FlowError::transient` | stop with a permanent / retryable failure | a reason missing after `with` | a typed failure the caller can classify (decoupled; `fail_is_classified` in `sim_script_steps.rs`) |
| `graph:` with `node name[ needs a, b]:` under it<br>`graph, at most (limit) at once:` | block | `graph` | every node once, each as soon as the nodes it needs have succeeded, longest remaining chain first, as many at once as the machine sustains; the value is the run's `GraphReport`<br>the same, under a limit that comes from somewhere named | a line under it that is not a `node`; a node needing itself, a node no line declares, or a cycle; a name declared twice; a concurrency bound typed as a number | a node starts only after every node it needs has succeeded; a node whose need failed never runs (generalized; `graph_needs_respected` in `sim_script_words.rs`); at most the bound of nodes run at once, and each node runs once (hyperscale; `graph_bounded` in `sim_script_words.rs`); each node runs in its own scope, `<graph>/<node>`, with its own key (ephemeral; `graph_node_scope` in `sim_script_words.rs`); a graph that cannot run is refused at the word, naming the node (idiomatic; refusal *graph with a cycle*) |
| `node name[ needs a, b]:` | block | `GraphNode::new` | one node of the enclosing `graph`: its body runs once, after `a` and `b` have succeeded | a `node` outside a `graph`; a name that is not one word | a node starts only after every node it needs has succeeded; a node whose need failed never runs (generalized; `graph_needs_respected` in `sim_script_words.rs`); only ever stands inside a `graph` (idiomatic; refusal *node outside a graph*) |
| `saga name:` with `compensate step:` after the steps it undoes | block | `compensated` | a named scope whose finished steps are undone, newest first, when a later line fails; its value is the body's | a name that is not one word | when the saga fails, the finished steps' undos run in reverse order, once each; a saga that succeeds runs none (generalized; `saga_reverse_once` in `sim_script_words.rs`); each undo runs under its own key, `<saga>/undo:<step>`, never the key of the step it reverses (ephemeral; `saga_undo_own_key` in `sim_script_words.rs`); an undo that fails is returned to the caller in place of the step's failure, and every undo still runs (decoupled; `saga_undo_failure_returned` in `sim_script_words.rs`); at most `MAX_COMPENSATIONS` undos registered; one past it fails the saga (hyperscale; `saga_bounded` in `sim_script_words.rs`) |
| `compensate step:` | block | `Compensations::add` | the undo of `step`, registered once that step has finished, run only if the saga later fails | a `compensate` outside a `saga`; a step no earlier line of the saga names | when the saga fails, the finished steps' undos run in reverse order, once each; a saga that succeeds runs none (generalized; `saga_reverse_once` in `sim_script_words.rs`); only ever undoes a step written before it in the same saga (idiomatic; refusal *compensate outside a saga*); a step the saga never ran is refused at the word, naming the steps it has (generalized; refusal *compensate an unknown step*) |
| `whenever x in batches, buffering N, drop oldest:` (or `drop newest`, `refuse`) | block | `pump` | each event of a live feed in arrival order, each in its own scope; `batches` is awaited for the next `Option<Vec<_>>` and `None` ends the feed; at most `N` events wait, and past that the policy decides; the value is the run's `PumpReport` | a feed with no `buffering N`; a buffer outside `1..=65536`; an overflow policy other than `drop oldest`, `drop newest` or `refuse` | never more than `N` events buffered, whatever the producer's rate; past it the declared policy, counted (hyperscale; `whenever_bounded` in `sim_script_feeds.rs`); events handled in arrival order, each in its own scope with its own key (generalized; `whenever_in_order` in `sim_script_feeds.rs`); a feed with no overflow policy is refused at the word, naming the three (idiomatic; refusal *whenever with no policy*) |
| `justify with (rules):` | block | `Scope::with_justification` | the block in a scope that answers to `rules`: every step, node and retry attempt inside asks them first, and is slowed, parked or stopped as they decide | a `justify` with no `with (rules)` | a step the rules stop fails with `Justified`, naming the rule, before its body runs (decoupled; `justify_stops_before_the_body` in `sim_script_feeds.rs`); the rules govern only the block's own scope, never a sibling's (multi-tenant; `justify_governs_its_block` in `sim_script_feeds.rs`); a `justify` with no rules is refused at the word, naming the form (idiomatic; refusal *justify with no rules*) |

# Closure matrix, Part 1: the twenty-two `lgwks_std` modules

Part of the [std × ast × deps closure matrix](std-ast-deps-closure-matrix.md),
which names the revision every row describes and what a row's state means.

The module inventory is read from `crates/lgwks-std/src/lib.rs`, which
declares exactly twenty-two `pub mod` items. Every one has a row. A module added
without a row is a coverage failure, and `scripts/check-doc-citations.py`
refuses it: it reads the `pub mod` names from `lib.rs` and the module column
below, and fails when either holds a name the other lacks.

### Two facts about this table that are easy to misread

- **`core` is not `#![no_std]`.** `core` is a cargo feature, and selecting it
  withdraws the default set — including `trace`. It is not a promise about the
  `no_std` attribute.
- **Feature availability and default availability are different facts.** `trace`
  is default-on; every other feature is default-off; `full` turns on twelve of
  them. A disabled selector does not silently acquire an optional engine.
